# BMI Calculator & Goal Tracker

A responsive BMI calculator and goal tracker built with React, TypeScript, and Tailwind CSS.

## Features

* Calculate BMI from height and weight
* Display BMI category
* Set and track a goal weight
* View previous BMI entries
* Delete previous entries
* Save BMI history and goal weight with localStorage
* Responsive design for different screen sizes

## Built With

* React
* TypeScript
* Tailwind CSS
* Vite
* localStorage

## Concepts Practiced

* React components
* `useState`
* `useEffect`
* Controlled inputs
* Props and TypeScript types
* Array methods
* Conditional rendering
* Local storage
* Responsive UI with Tailwind CSS

## Getting Started

Clone the repository:

```bash
git clone https://github.com/jzzmiiinn/BMI-Calculator.git
```

Navigate to the project:

```bash
cd BMI-Calculator
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL shown in your terminal.

## Purpose

This project was built to practice React and TypeScript fundamentals while creating a practical application with state management, persistent data, and responsive UI.
